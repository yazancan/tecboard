# TechBoard

Projeto de interface web desenvolvido durante a formação de front-end da Alura, com foco na construção de layouts e interatividade com JavaScript.

## 🚀 Tecnologias
- HTML
- CSS
- JavaScript

## 💡 Funcionalidades
- Layout responsivo
- Navegação entre seções
- Alternância entre modo claro e escuro (dark mode)

## 🧠 Aprendizados
- Estruturação de páginas com HTML semântico
- Estilização com CSS
- Manipulação do DOM com JavaScript

## ✨ Destaque
A funcionalidade de alternância entre modo claro e escuro foi desenvolvida por mim, aplicando conceitos de manipulação de classes e eventos no JavaScript.
